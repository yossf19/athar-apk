# أثَر — المدينة التي تتذكّرك
ATHAR: The City Remembers

لعبة مغامرة وغموض ثلاثية الأبعاد تعمل في المتصفح، مبنية بـ Three.js وVite، وتعمل باللمس على الهاتف والتابلت.

## ماذا تتضمن النسخة الأولى
- شخصية ثلاثية الأبعاد مؤقتة (أشكال هندسية) مع مشي وتسارع وتباطؤ وتصادم مع الجدران.
- كاميرا منظور الشخص الثالث: تتبع سلس، تدوير بالسحب، ومنع الدخول في الجدران.
- مدينة صغيرة: زقاق رئيسي، مبانٍ متنوعة الارتفاع، أطلال، منصة الأثر الزمني، والبوابة المعدنية ولوحة الإشارات.
- **الأثر الزمني**: هيئة شبه شفافة تعيد مشهداً سابقاً، مع إيقاف مؤقت وإعادة تشغيل، ونظام تسجيلات قابل للتوسعة في `src/echo-system.js`.
- **اللغز الأول**: تسلسل الإشارات الضوئية يُستنتج من الأثر فقط. الترتيب الصحيح يفتح البوابة، والخطأ يعيد ضبط اللوحة مع رسالة توضيحية.
- واجهة عربية كاملة من اليمين إلى اليسار، وإعدادات للصوت والحساسية والجودة.
- حفظ التقدم محلياً عبر `localStorage`، وإعادة ضبط بموافقة اللاعب.
- صوت مولّد برمجياً بالكامل عبر Web Audio API (لا ملفات صوتية خارجية، لذا لا توجد مشكلات ترخيص).

## التحكم
| الجهاز | الحركة | الكاميرا | التفاعل |
|---|---|---|---|
| هاتف / تابلت | عصا على الجهة اليسرى | سحب على الجهة اليمنى | زر «تفاعل» |
| حاسوب | WASD أو الأسهم | (قيد التطوير) | مفتاح E |

زر «إعادة الأثر» يعيد تشغيل آخر أثر فحصته، وزر «حساسية» يبدّل بين ثلاث درجات، وزر الإيقاف المؤقت يفتح قائمة الإعدادات.

## التشغيل من الهاتف (بدون حاسوب)
المشروع يحتاج Node.js وnpm. أسهل طريقة من الهاتف هي استخدام بيئة تطوير سحابية تدعم Vite مثل **StackBlitz** أو **CodeSandbox** (من المتصفح):

1. افتح بيئة Vite جديدة (Vite + Vanilla JS) في المتصفح.
2. استبدل الملفات بملفات هذا المشروع، أو ارفع المجلد كاملاً إن كانت البيئة تدعم الرفع.
3. تأكد أن `package.json` يحتوي على `three` بالإصدار `0.160.0` و`vite` بالإصدار `5.4.2`.
4. شغّل الأمر `npm install` ثم `npm run dev`.
5. افتح الرابط الذي تعرضه البيئة في المتصفح. للاختبار من هاتف آخر أو للمشاركة استخدم `npm run build` ثم انشر مجلد `dist`.

## الأوامر
- `npm install` لتثبيت الاعتماديات.
- `npm run dev` لتشغيل خادم التطوير.
- `npm run build` لإنشاء نسخة الإنتاج في `dist/`.
- `npm run preview` لمعاينة نسخة الإنتاج محلياً.

## الحفظ
يُحفظ التقدم في localStorage، أي أنه مرتبط بهذا المتصفح وبهذا الجهاز فقط. إذا كان التخزين معطلاً (وضع التصفح الخاص مثلاً) تستمر اللعبة دون حفظ وتظهر رسالة توضيحية.

athar-3d/

## استبدال الشخصية بنموذج GLB
`src/player.js` يبني الشخصية من أشكال هندسية. لاستبدالها بنموذج glTF/GLB لاحقاً، حمّل النموذج عبر `GLTFLoader` في مكان بناء `root`، واحتفظ بالدالة `update` كما هي مع تعديل تدوير الأطراف لتتوافق مع عظام النموذج.

## إضافة أثر جديد
أضف تعريفاً جديداً إلى `ECHO_DEFS` في `src/echo-system.js` بالحقول `id` و`title` و`position` و`steps`. الخطوات المتاحة: `move` و`wait` و`lamp` و`event`.

## ما الذي تم اختباره فعلياً
راجع قسم التسليم في رد المساعد لمعرفة الاختبارات التي أُجريت فعلياً وتلك التي لم تُجرَ.
